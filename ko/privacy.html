개인정보 처리방침

수집하는 데이터

이 앱은 개인정보를 수집하지 않으며 사진, 비디오, 미디어 정보, 사용 기록을 자동으로 업로드하지 않습니다. 사용자가 직접 공유하면 선택한 콘텐츠가 시스템을 통해 지정한 앱이나 받는 사람에게 전달되며, 개발자는 이 콘텐츠를 받지 않습니다.

사진 접근

사진 접근 권한은 사진과 비디오를 표시하고, 필터링하고, 앨범으로 정리하고, 즐겨찾기에 추가하고, 삭제하고, 사용자의 요청에 따라 공유하는 데 사용됩니다. 원본이 iCloud에만 있다면 iOS가 시스템 사진 서비스를 통해 원본을 다운로드할 수 있습니다. 이 앱은 사용자의 iCloud 계정 정보를 받지 않습니다.

기기에 저장되는 진행 상황

다음에 이어서 사용할 수 있도록 미디어 필터, 보기 순서, 마지막 진행 방향, 현재 위치, 삭제할 항목의 로컬 식별자를 현재 기기에 저장하며, 기기 밖으로 전송하지 않습니다.

삭제와 복구

휴지통을 탭하고 iOS 시스템 확인을 거친 뒤에만 사진이나 비디오가 삭제됩니다. 삭제한 항목은 보통 시스템 앨범의 ‘최근 삭제된 항목’에 30일 동안 보관됩니다.

타사 서비스

이 앱에는 광고, 분석, 로그인 또는 앱 간 추적 서비스가 포함되어 있지 않습니다.

사용자가 시작한 공유

사용자가 공유를 누르고 받는 사람을 선택한 경우에만 iOS 공유 시트가 선택한 사진이나 영상을 해당 앱 또는 받는 사람에게 전달합니다. 공유 파일은 기기에서 준비되며 개발자 서버를 거치지 않습니다. 받는 사람이 콘텐츠를 처리하는 방식에는 선택한 서비스와 해당 개인정보 처리방침이 적용됩니다. 시스템 공유 시트에서 취소할 수도 있습니다.

이 웹사이트 방문

사용자가 이 지원 웹사이트를 직접 열 때에만 사이트 호스팅 및 네트워크 보안 제공업체가 페이지 전송, 악용 방지와 보안 보호에 필요한 네트워크 정보를 처리할 수 있습니다. 여기에는 IP 주소, 브라우저 정보와 보안 쿠키 등이 포함됩니다. 개발자는 이 정보를 광고, 사이트 간 추적 또는 프로파일링에 사용하지 않습니다.

지원 이메일 보내기

지원팀에 이메일을 보내면 개발자는 이메일 주소, 메시지 내용과 사용자가 자발적으로 첨부한 파일을 받습니다. 이 정보는 지원 요청에 답변하고 문제를 해결하는 데만 사용되며, 해당 요청을 처리하는 데 필요한 기간 동안만 보관됩니다.
